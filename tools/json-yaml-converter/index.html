Frequently Asked Questions

Is the YAML parser complete?
It supports common YAML features: objects, arrays, strings, numbers, booleans, and null. It may not handle all edge cases of the full YAML spec.
Can I convert YAML with anchors?
Basic anchors and aliases are supported, but complex YAML features may not be converted correctly.
Does it preserve order?
JSON objects preserve insertion order. YAML mappings are also ordered by default in this implementation.
