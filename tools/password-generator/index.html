Frequently Asked Questions

Is the random source secure?
Yes, passwords are generated using crypto.getRandomValues(), which is cryptographically secure.
How is strength calculated?
Strength is estimated based on length and character variety. It's a heuristic, not a guarantee.
Are generated passwords stored?
No. Passwords are generated and displayed in memory only.
