# Contributing to DevBox Tools

Thank you for your interest in contributing! DevBox Tools is open source and we welcome contributions of all kinds.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Guidelines

- All tools must run client-side only (no server-side code)
- No external libraries unless absolutely necessary
- Follow the existing code style
- Test your changes locally before submitting
- Update documentation if needed

## Code of Conduct

Be respectful. We're here to build useful tools for developers.
